03 · Gaps in the plan

Nine additions, each with a test that fails today

G1 · BLOCKS #238 ACCEPTANCE
Contrast is checked against an opaque surface

TOKENS.md gives Dx Dark error 5.0:1. The surface is 94% opaque, so over a white scene it drops to 4.41:1 and the #238 EditMode test would pass while players see a fail. Make the test composite over three backdrops, and split the role: keep #EC4661 for glyphs and chips, use #FF7A8E for error text (6.62:1 worst case). The selection outline #2B6B45 is 2.58:1, under the 3:1 that outlines need. #347E52 gives 3.34:1.

G2 · APCA AS A SECOND GATE
13 px muted text is legal but weak

Timestamps and shell rows use #8B949E: 5.36:1 worst case, APCA Lc 42. WCAG 2 stays the gate; add APCA as an advisory column. Raising muted to the family's #9AA3AF gives 6.46:1, Lc 50, at no brand cost.

G3 · XAG 101 / 102
Text scale and a 7:1 theme

Sizes are fixed (log 13 px). Add a Text size setting (S 13 · M 15 · L 18) that scales rows, and a Dx High Contrast theme where every role reaches 7:1, as Xbox guideline 102 asks of high-contrast modes.

G4 · 126 LEGACY THEMES
Decide what happens to the old set

#238 adds three new themes but does not say what happens to the 115 failing ones. Proposal: move them to an optional Classic themes pack, have the converter repair them to 4.5:1 by moving lightness in OKLCH, and show a contrast chip in the picker.

G5 · MOTION
Motion presets need "None"

#240 replaces curves with presets. Ship None · Subtle · Snappy, default Subtle at 120 ms or less. None sets every transition to 0 ms, and a test reads the resolved duration.

G6 · PERFORMANCE BUDGET
A budget for the new chrome, not only the log

The header, chips and tabs add elements. Set three budgets from a first measurement and fail CI on regressions: VisualElement count when open, main-thread ms for open and first frame, and 0 B/frame when idle with 10,000 lines. The log stays a FixedHeight ListView, so wrapped rows need a measured-height plan.

G7 · VERSION-GATED POLISH
Pretty on 2021.3, nicer on 6.3+

The base design uses only 1 px lines and surface steps, no shadows. On Unity 6.3+ add native SVG glyphs and icons, and an optional backdrop blur filter behind the surface, behind UNITY_6000_3_OR_NEWER guards. The contrast test must not rely on the blur.

G8 · SCREEN READERS (ROADMAP)
Expose the log and Actions to assistive tech

Unity 6's Accessibility module needs a hand-built AccessibilityHierarchy. A time-boxed spike: the newest error, the input row and each Actions Run button as nodes, tested with TalkBack and VoiceOver. Outcome decides whether it becomes an issue or stays in ROADMAP.

G9 · SYNTAX AND COMPLETION
The input line has no color at all

Nothing in Runtime/ uses rich text, and completions are a horizontal row of buttons. #241 does not cover argument colors, signature help or errors before Enter. The Syntax board defines all three and the tests T10–T13.

04 · Principles from the research

What modern developer tools agree on

Keyboard first, pointer complete
Warp groups each command with its output and drives everything from the keyboard. Every terminal action gets a key, a pad path and a pointer target of 44 px on touch.
Meaning never by color alone
Each severity has a glyph and a label (■ ▲ · ›). Chips show counts as text. Selection is fill plus outline.
Elevation by lightness steps
Dark UIs read depth from surface steps, not shadow. This fits the 2021.3 USS floor and stays crisp at any scale.
Semantic tokens, two layers
Primitives stay fixed; only the role layer changes per theme. Dark is tuned on its own, not inverted. OKLCH makes lightness edits predictable.
Virtualize every list
ListView makes rows on demand and recycles them on scroll. Keep row height fixed per text size, and never use a horizontal layout in a virtualized list.
Inspectors bind, validate, explain
UI Toolkit binding gives undo for free. Group by task, validate inline with a fix button, and show live Play Mode state, as Odin and Tri Inspector do.
05 · Method

Red first, then green, then record the number

1 · Hypothesis
One sentence that names a metric and a direction.
2 · Red
A test, capture diff or audit that fails on master. Commit it first.
3 · Green
The smallest change that passes it, with no other baseline regressions.
4 · Record
Before and after numbers in the PR. A gate keeps the new floor.

Instruments already in the repo: golden captures (#236, S1–S6, E1–E4), allocation tests (#108, #111), the MCP capture bridge. New: the contrast audit, an inspector overflow sweep, and a 5-person first-run usability study. Tasks are on the red-green board.
